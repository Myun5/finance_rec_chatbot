# 🏦 하나 금융상품 추천 서비스

사용자의 회원정보와 투자성향을 기반으로 예금상품을 추천하고,  
OpenAI API를 활용한 AI 금융상담 챗봇 **하나봇**을 통해 금융상품을 검색·비교할 수 있는 웹 서비스입니다.

사용자의 나이, 직업, 소득, 투자성향 등의 정보를 활용하여 CSV에 저장된 실제 금융상품 데이터를 분석하고 개인에게 적합한 상품을 추천합니다.

## 📖 프로젝트 소개

**하나 금융상품 추천 서비스**는 회원정보와 금융상품 데이터를 기반으로 사용자에게 적합한 예금상품을 추천하는 서비스입니다.

사용자는 회원가입 과정에서 다음 정보를 입력합니다.

- 나이
- 성별
- 직업
- 연소득
- 투자성향
- 프로필 이미지

입력된 사용자 정보와 `예금목록.csv`의 금융상품 데이터를 비교하여 추천 점수를 계산하고 적합한 상품을 제공합니다.

또한 OpenAI의 `gpt-4o-mini` 모델을 활용한 **하나봇**을 통해 금융상품에 대해 자연어로 질문할 수 있습니다.

예시:

> 금리가 높은 예금상품 추천해줘

> 1년 동안 가입할 수 있는 상품 알려줘

> 내 투자성향에 맞는 상품 3개 추천해줘

> 기본금리와 최고금리가 높은 상품을 비교해줘

## ✨ 주요 기능

### 1. 회원가입

사용자는 다음 정보를 입력하여 회원가입할 수 있습니다.

- 아이디
- 비밀번호
- 이름
- 이메일
- 성별
- 나이
- 투자성향
- 직업
- 연소득
- 프로필 이미지

회원가입한 정보는 SQLite의 `users` 테이블에 저장됩니다.

---

### 2. 비밀번호 암호화

사용자의 비밀번호를 평문으로 저장하지 않고 `PBKDF2-HMAC-SHA256` 방식으로 해싱하여 저장합니다.

각 비밀번호마다 임의의 Salt 값을 생성하여 보안성을 높였습니다.

```text
PBKDF2-HMAC-SHA256
+ Random Salt
+ 100,000 Iterations
```

---

### 3. 로그인 / 로그아웃

로그인 성공 시 Session을 통해 사용자의 로그인 상태를 유지합니다.

로그인하지 않은 사용자가 메인 페이지 또는 챗봇 페이지에 접근하는 경우 로그인 페이지로 이동합니다.

주요 URL:

```text
/login
/signup
/main
/chatbot
/logout
```

---

### 4. 프로필 이미지 등록

회원가입 시 사용자가 프로필 이미지를 등록할 수 있습니다.

지원하는 이미지 확장자:

```text
.jpg
.jpeg
.png
.gif
.webp
```

업로드된 이미지는 다음 경로에 저장됩니다.

```text
static/profiles/
```

파일명은 UUID를 사용하여 생성합니다.

---

### 5. 금융상품 CSV 데이터 활용

금융상품 데이터는 다음 CSV 파일에서 불러옵니다.

```text
static/예금목록.csv
```

Pandas를 사용하여 금융상품 데이터를 처리합니다.

한글 CSV 인코딩 문제를 방지하기 위해 다음 인코딩을 순차적으로 확인합니다.

```text
utf-8-sig
utf-8
cp949
euc-kr
```

금융상품의 주요 데이터는 다음과 같습니다.

```text
금융사
상품명
기본금리
최고금리
가입기간
가입금액
가입방법
가입대상
상품유형
상세정보
상세URL
```

## 🎯 추천 시스템

메인 페이지에서는 사용자 정보와 금융상품 정보를 비교하여 맞춤형 예금상품을 추천합니다.

추천 시 다음 정보를 활용합니다.

### 투자성향

```text
안정형
안정추구형
위험중립형
적극투자형
공격투자형
```

투자성향에 따라 기본금리와 최고금리에 서로 다른 가중치를 부여합니다.

예를 들어 안정형 사용자는 기본금리 비중을 상대적으로 높게 평가하고, 적극투자형 또는 공격투자형 사용자는 예금상품 내에서 상대적으로 높은 최고금리를 가진 상품을 더 우선적으로 확인합니다.

---

### 나이

연령대에 따라서도 상품의 추천 점수가 조정됩니다.

```text
20대 이하
30 ~ 40대
50대 이상
```

상품의 가입대상 및 상품 설명에 연령과 관련된 조건이 포함되어 있으면 추가 점수를 부여합니다.

---

### 직업

사용자의 직업과 상품의 가입조건을 비교하여 관련성이 높은 상품에 추가 점수를 부여합니다.

---

### 연소득

사용자의 연소득도 상품 추천 점수 계산에 사용됩니다.

```text
3,000만 원 미만
3,000만 원 이상 ~ 7,000만 원 미만
7,000만 원 이상
```

---

### 금리

상품 추천 시 다음 두 금리를 함께 활용합니다.

```text
기본금리
최고금리
```

상품별로 추천 점수를 계산한 뒤 점수가 높은 순서대로 정렬하여 사용자에게 추천합니다.

메인 페이지에서는 기본적으로 **추천 상품 3개**를 제공합니다.

## 🤖 AI 챗봇

서비스에는 금융상품 상담 전용 AI 챗봇인 **하나봇**이 포함되어 있습니다.

접속 주소:

```text
/chatbot
```

사용자가 질문을 입력하면 다음 과정을 거쳐 답변을 생성합니다.

```text
사용자 질문
    ↓
질문의 키워드 추출
    ↓
예금목록.csv 금융상품 검색
    ↓
관련 상품 최대 12개 추출
    ↓
회원정보 + 상품정보 + 질문 결합
    ↓
OpenAI GPT-4o-mini 호출
    ↓
금융상품 상담 답변 생성
```

---

### 금융상품 검색

사용자의 질문에서 키워드를 추출하여 다음 항목을 검색합니다.

```text
금융사
상품명
기본금리
최고금리
가입기간
가입금액
가입방법
가입대상
상품유형
상세정보
```

예를 들어 다음과 같은 질문이 들어올 경우

```text
금리가 높은 예금 추천해줘
```

`금리`, `높은`, `고금리`, `최고금리` 등의 표현을 인식하여 최고금리가 높은 상품의 점수를 높입니다.

---

### 사용자 맞춤 상담

하나봇은 현재 로그인한 사용자의 정보를 함께 참고합니다.

```text
이름
나이
성별
투자성향
직업
연소득
```

따라서 단순히 금리가 높은 상품을 보여주는 것이 아니라 사용자의 특성을 고려하여 상품을 설명할 수 있습니다.

---

### 금융상품 비교

여러 상품을 추천하거나 비교하는 경우 Markdown 표 형식으로 답변하도록 구성되어 있습니다.

예시:

```text
| 금융사 | 상품명 | 기본금리 | 최고금리 | 가입기간 | 가입금액 |
|---|---|---:|---:|---|---|
| OO은행 | OO정기예금 | 3.00% | 3.50% | 12개월 | 100만원 이상 |
```

추천 상품은 일반적으로 3~5개 정도로 제한하여 가독성을 높였습니다.

---

### 대화 기록 활용

프론트엔드에서 전달된 최근 대화 기록을 AI에게 함께 전달합니다.

최근 최대 12개의 사용자 및 AI 메시지를 참고하여 이전 대화의 문맥을 어느 정도 유지할 수 있도록 구현했습니다.

## 🚀 실행 방법

### 1. 프로젝트 다운로드

GitHub에서 프로젝트를 Clone 합니다.

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

프로젝트 폴더로 이동합니다.

```bash
cd <PROJECT_FOLDER>
```

---

### 2. 필요한 라이브러리 설치

다음 라이브러리를 설치합니다.

```bash
pip install fastapi uvicorn jinja2 python-multipart pandas openai python-dotenv itsdangerous
```

또는 `requirements.txt`를 사용하는 경우

```bash
pip install -r requirements.txt
```

---

### 3. `.env` 파일 생성

프로젝트 최상위 폴더에 `.env` 파일을 생성합니다.

```text
main.py
.env
static/
templates/
```

`.env` 파일에 OpenAI API Key를 입력합니다.

```env
OPENAI_API_KEY=YOUR_OPENAI_API_KEY
SESSION_SECRET=YOUR_SESSION_SECRET
```

---

### 4. 금융상품 CSV 확인

다음 위치에 금융상품 CSV 파일이 있어야 합니다.

```text
static/예금목록.csv
```

CSV가 존재하지 않으면 금융상품 추천 및 챗봇의 상품 검색 기능이 정상적으로 작동하지 않습니다.

---

### 5. 서버 실행

터미널에서 다음 명령어를 실행합니다.

```bash
python main.py
```

정상 실행되면 다음과 같이 표시됩니다.

```text
============================================================
하나 금융상품 추천 서비스
http://localhost:1122
============================================================
```
